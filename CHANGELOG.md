# Changelog

Dates are day first. Versions follow semantic versioning.

## 1.0.0 (06/11/2026)

First release.

- Encrypted vault with thirteen item types, eight categories and custom categories
- Attachments up to 25 MB, encrypted on the device
- Dashboard, reminders and password health
- OneDrive folder sync with per-record merge and tombstones, plus moving backups by hand
- CSV import with preview, CSV export, encrypted backups, bringing back old items as copies
- Offline use, install as an app, dark and light themes, phone layout to 320 px

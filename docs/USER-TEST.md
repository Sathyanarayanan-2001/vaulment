# Checks only you can run

About 15 minutes, with made-up data first.

1. **Windows laptop:** Sync, Choose folder, pick a OneDrive folder. Wait for Saved. Check that a `vaulment-save-…json.gz` file appears.
2. **Second laptop:** Bring my vault to this device, same folder. Add an item on each. Press Sync now on both, twice. Both should show both items.
3. **Phone:** open the address in Chrome. See whether Choose sync folder appears and whether OneDrive is offered. If not, use Make a backup and Open a backup.
4. **Phone keyboard:** on a new bank account, tap the lowest field. It must stay visible above the keyboard.
5. **Offline:** open once, turn on airplane mode, reopen. It should open and unlock.
6. **Install:** install on the laptop and phone.
7. **Recovery:** on a throwaway vault, lock and use the recovery key.

Report anything that differs. If folder sync on Android works, the hand-moved backup is not needed there.
